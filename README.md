# Excel VBA School Management System

## Project Overview
The Excel VBA School Management System is a school records management application developed using Microsoft Excel and Visual Basic for Applications (VBA). It helps schools manage student and teacher records, track fee payments, calculate outstanding balances, and print receipts.

## Features

### 1. Student Management
- Register and maintain student records.
- Assign and manage student admission numbers.
- Store and organise student information.
- Search and manage student records.

### 2. Teacher Management
- Register and maintain teacher records.
- Assign teacher identification numbers.
- Store and organise teacher information.

### 3. School Fees Management
- Record and maintain student fee payment transactions.
- Calculate the total fees paid by each student.
- Automatically calculate outstanding fee balances.
- Track students' fee payment status.
- Maintain fee payment records for reference.

### 4. Receipt Generation and Printing
- Generate and print school fee payment receipts.
- Generate and print student admission receipts.
- Provide printed documentation for fee payments and student admission.

### 5. Login and Dashboard
- Provide a login form for accessing the system.
- Display a HOME dashboard for navigating between worksheets.
- Use VBA macros to control worksheet visibility and navigation.

### 6. Automated Record Management
- Automate data entry and record organisation using VBA.
- Manage student and teacher records through Excel forms.
- Reduce repetitive manual work and improve record management efficiency.

## Technologies Used
- Microsoft Excel
- Visual Basic for Applications (VBA)
- Excel worksheets, UserForms, and macros

## How to Use
1. Download the Excel macro-enabled workbook (`.xlsm`).
2. Open the workbook using desktop Microsoft Excel.
3. Enable macros only if you trust the workbook and its source.
4. Log in through the system's login form.
5. Use the HOME dashboard to access the available school management modules.
6. Enter student, teacher, and fee payment information as required.
7. Generate and print the relevant payment or admission receipts.

## Project Purpose
This project demonstrates how Microsoft Excel and VBA can be used to automate school administration, maintain records, manage fee payments, calculate outstanding balances, and generate receipts.

## Security Notice
This project is intended for educational and demonstration purposes. Do not upload real student records, confidential school information, or passwords to a public repository.
